✔ Create Account

User enters first name, last name, initial deposit, and account type.

System automatically generates a unique account number.

Details are saved in bank_data.txt.

✔ Deposit Balance

Enter account number and amount.

Balance updates and overwrites the original stored data.

✔ Withdraw Balance

Enter account number and amount.

Ensures balance is updated correctly.

✔ Check Balance

Quick lookup of current balance using account number.

✔ Persistent Storage

Uses plain text file (bank_data.txt) to save and update data.

No database required.
